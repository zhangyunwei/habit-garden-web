# 习惯花园：已确认画风提示词

## 唯一参考与使用方式

以同目录的 `唯一视觉基准.png` 为唯一视觉基准，即用户重新上传的珊瑚橙屋顶、卡皮巴拉头顶小黄鸟、熊猫闭眼吃叶子的游戏效果图。

此前按“绿叶屋顶 A”生成的素材不作为本次风格依据。不要再用 A/B/C 字母推断用户选择。

每次生成必须同时上传基准图。使用“通用画风提示词 + 对应素材提示词 + 负面约束”。文字提示用于辅助锁定画风，不能保证单凭文字就复现角色；动物必须持续引用基准图。

## 1. 通用画风提示词

```text
严格参考上传图片，延续同一款休闲种植经营手游的美术风格。整体为简洁、可爱、温暖、精致的二维卡通手绘，采用轻度斜俯视游戏视角。造型圆润饱满，轮廓清楚，细节适度，像经过统一美术设计的游戏场景和角色。

使用柔和的暖棕色、灰棕色与深绿色描边，线条干净，粗细自然，避免粗重纯黑外轮廓。以清晰的大色块组织画面，在色块内部添加少量柔和明暗过渡和简化的手绘色面，具有轻微体积感，但仍明显是二维绘制。不要厚重笔触、颗粒纸纹、写实材质或塑料般反光。

主色为浅嫩绿草地、鼠尾草绿与青绿色树冠；搭配珊瑚橙屋顶、奶油米白墙面、蜂蜜色木材和清透蓝绿色水面。色彩明快、柔和、协调，避免荧光绿、大片黄褐色和过强对比。阳光温暖而均匀，阴影柔软，空间清爽。

树叶以圆润团块分层概括，草地保留大面积干净色面，只点缀少量小草与花朵。建筑比例略有童话感，屋顶曲线柔软，门窗小巧。植物、动物、建筑、道具与界面图标必须使用一致的描边、配色和明暗方式。画面精致，但不依靠堆砌纹理与装饰制造细节。

保持参考图中的角色设计和视觉气质，不重新设计动物的五官、身形、动作或表情。
```

## 2. 完整游戏界面效果图

```text
生成一张与参考图同画风的竖屏种植经营游戏界面，约 9:16，无手机外框。左上方是珊瑚橙色弧形屋顶、奶油墙面的小屋，木门圆润，周围有少量藤叶和白色花朵；右上方是绿白条纹遮棚的木质种子小铺。远处有青绿树冠、小瀑布和蓝绿色水面。

中央保留宽敞的浅绿色草地。8 块土地采用参考图相同的右倾斜平行四边形地面，分成两排，每排四格，留出清晰间距。土地是贴近地面的薄土层，暖棕色土面、柔和圆角、浅绿色窄边，所有地块保持同一方向与透视。不是正面方形花箱，不添加高木框。

地块中分别展示雏菊、胡萝卜、草莓、向日葵、南瓜、幼芽以及空土地。左侧放置参考图同款头顶小黄鸟的卡皮巴拉，右侧放置同款闭眼吃叶子的熊猫，严格保留两只动物的身形与表情。

顶部是奶油色圆角状态栏、嫩芽等级标识、绿色经验条、金币和仓库入口。底部是奶油色圆角工具栏，带柔和棕色轮廓和轻微厚度，图标分别为小商店、种子袋、收获篮、木牌和齿轮。文字使用清楚的圆润中文：商店、播种、收获、编辑、设置。

画面轻松、可爱、清晰，土地和操作按钮容易辨认。不要复制其他游戏的排行榜、任务、公会、聊天栏或付费入口。
```

## 3. 卡皮巴拉：锁定造型

```text
以参考图左侧卡皮巴拉为唯一角色依据，保持同一只角色，不重新设计。

焦糖浅棕色身体，头部圆钝，口鼻部稍长而宽，身体呈上窄下宽的饱满梨形，短小圆耳，短腿和小脚掌，坐姿稳定。头部朝右，眼睛是闭合的短弧线，表情平静、慵懒、满足。口鼻区域只有简洁柔和的棕色结构线，不突出大鼻孔，不画露齿笑，不画夸张腮红。

头顶停着参考图同款小黄鸟：圆圆的小身体、橙黄色小嘴、简单翅膀与小尾巴。黄鸟与卡皮巴拉构成一个整体角色组合。卡皮巴拉嘴里不叼叶子，手里不拿物品。

描边为柔和暖棕色，明暗简单柔和，保留参考图的小幅手绘色面，避免厚重黑边、逼真毛发、肌肉结构和高光塑料感。姿势、头身比例、五官位置与参考图保持一致。

单独输出完整角色，四周留出余量，不裁切耳朵、黄鸟或脚掌，无文字，无场景和土地。若要求透明素材，输出真实透明 Alpha，不能把棋盘格画进背景。
```

## 4. 熊猫：锁定造型

```text
以参考图右侧熊猫为唯一角色依据，保持同一只角色，不重新设计。

熊猫坐在地面，头大而圆，身体短胖、四肢圆钝，奶油白脸部与腹部，暖深灰色耳朵、眼圈和四肢。眼睛闭合成柔和弧线，表情安静、满足。两只前掌将一片绿色叶子捧在嘴边，表现慢慢吃叶子的动作。保留参考图中的黑白区域分布、头部朝向和后脚造型。

不要改成睁眼卖萌，不要画闪亮大眼睛、吐舌头、露齿笑、夸张粉色腮红或明显的脚底粉色肉垫。不要增加大束竹叶和复杂毛发。背景竹子不应与角色粘连为同一素材。

使用参考图一致的柔和深棕灰描边、干净色块与少量柔软明暗，不做厚黑轮廓的矢量贴纸，也不做三维玩偶。

单独输出完整角色，四周留白，不裁切耳朵、叶子、手掌和脚掌，无文字，无场景和土地。若要求透明素材，输出真实透明 Alpha，不能把棋盘格画进背景。
```

## 5. 游戏背景

```text
根据参考图制作同画风的竖屏花园背景层。保留珊瑚橙色圆弧瓦顶小屋、奶油墙面、木门窗、绿白条纹棚种子小铺、浅青绿色水面、圆润树冠、木围栏和少量花卉。建筑与水体集中在上部及地图边缘，中下部是宽敞、连续、干净的浅绿色草地，可供玩家摆放土地、动物和装饰。

背景中不绘制土地、作物、动物、可移动装饰、金币、文字、按钮或 HUD。不要把卡皮巴拉、熊猫、猫咪或黄鸟画死在背景中。前景素材由游戏独立叠加。

叶片与石头用简洁圆润色块概括，保留柔和描边和参考图的轻微手绘质感，避免密集草纹和过度复杂的森林。构图服务于可玩区域，不用大片景物遮住地块。
```

## 6. 土地与植物

```text
土地：参考图同款右倾斜平行四边形地块，斜俯视、轻薄贴地，四角略圆。两组对边分别平行，地块朝向统一，暖棕色土壤搭配浅绿色窄草边、少量简化土块和柔和投影。不要生成正面矩形、梯形、高木箱、厚重石台或不规则圆形土地。

植物：雏菊、胡萝卜、草莓、向日葵、南瓜，使用参考图一致的简洁可爱造型。叶片圆润厚实、数量克制，花朵与果实略微夸张但容易识别。白色雏菊配黄色花心；橙色胡萝卜配清楚的绿叶；草莓两颗红果配少量浅黄籽；向日葵花盘饱满、黄色花瓣整齐；南瓜橙色圆胖、带简洁瓜棱和弯曲瓜蒂。

每种植物分别制作播种、幼苗、生长、成熟四阶段，同种植物维持统一画布、地面锚点、描边粗细和配色。前期小巧，成熟阶段更饱满。植物素材不自带完整土地；土地独立输出。
```

## 7. 装饰与界面

```text
装饰：小花盆、石板小路、木质长椅、庭院路灯、小型喷泉。保持参考图的圆润比例、轻度斜俯视角、蜂蜜木色与奶油石色、暖棕描边、柔和简单明暗。单体完整，不附带其他角色或成片背景，便于独立摆放。

界面：奶油米白圆角面板、柔和暖棕外轮廓、少量浅金色边缘与轻微厚度。绿色进度条，蜂蜜金色金币，种子袋、木牌、收获篮、商店和齿轮采用同一套卡通手绘语言。图标轮廓清晰，细节克制，小尺寸仍容易辨认。中文由界面程序排版时保持圆润清楚；单独图标素材不绘制文字。

避免金属机械风、写实木纹、厚浮雕、玻璃拟态、霓虹光效和现代办公后台组件感。
```

## 8. 通用负面提示词

```text
写实摄影，三维渲染，塑料玩偶，黏土质感，厚重油画，明显水彩纸纹，密集噪点，脏乱笔触，荧光高饱和，纯黑粗描边，强烈高光，复杂毛发，尖锐棱角，过度简化的扁平矢量标志，错误动物比例，重新设计五官，睁眼熊猫，吐舌头，露齿笑，夸张腮红，卡皮巴拉嘴叼叶子，缺少头顶小黄鸟，正面方形土地，高木框花箱，透视方向不统一，拥挤界面，多余玩法入口，文字乱码，水印，棋盘格伪透明背景。
```

## 检查重点

- 先比较动物的头身比例、闭眼表情、动作和配件，再比较整体配色。不能只因“可爱、棕色、黑白色”就判断角色一致。
- 不将背景里的竹子、椅子、土地或界面元素粘连到动物素材。
- PNG 文件名不代表存在透明通道，必须检查实际 Alpha；不把棋盘格背景当作透明结果。
- 效果图上的等级经验数字只是视觉示例，游戏实际数值仍按原 PRD。
